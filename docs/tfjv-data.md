# TARGET frontier JV 連携

予想の**印**と、レースごとに書き溜めた**成績コメント**は DB ではなく TARGET frontier JV（以下 TFJV）のデータファイルに入っている。`g1_predict/modules/utils/tfjv.py` がこれらを直接読み書きする。

対象ディレクトリは環境変数 `TFJV_DATA_DIR`（既定 `/KeibaAI/repos/g1-predict/MY_DATA`）。

```
$TFJV_DATA_DIR/
├── UM{YY}{開催回}{競馬場略称}.DAT   # 印
└── KEK_COM/
    └── 20{YY}/
        └── KC{競馬場コード}{YY}{開催コード}.DAT   # 成績コメント
```

`MY_DATA/` は `.gitignore` 済みで、リポジトリにはデータを置かない。

## race_code からファイル名への変換

`race_code_to_tfjv()` が 16桁のレースコードを TFJV のファイル名要素に変換する。

| 要素 | 求め方 | 例（`2026061409030411`） |
| --- | --- | --- |
| 競馬場コード | `race_code[8:10]` | `09`（阪神） |
| 年下2桁 | `race_code[2:4]` | `26` |
| 開催コード | 開催回と開催日目をそれぞれ**16進1桁**にして連結 | 3回4日目 → `34`（10回12日目なら `AC`） |
| レース番号 | `race_code[14:16]` | `11` |

競馬場略称（ファイル名に使う1文字）: `01`札 / `02`函 / `03`福 / `04`新 / `05`東 / `06`中 / `07`名 / `08`京 / `09`阪 / `10`小。未対応のコードを渡すと `ValueError`。

## 印ファイル（UM*.DAT）

固定長バイナリ。1レコード264バイト、1行44バイト。印は5行目（0起算で4行目）の先頭42バイトに、Shift_JIS の2バイト文字として馬番順に並ぶ。

読めるのは次の7種類。TARGET 上で「消」を付けても、このマップに無いため読み込まれない。

| 印 | バイト列 |
| --- | --- |
| ◎ | `81 9D` |
| ○ | `81 9B` |
| ▲ | `81 A3` |
| △ | `81 A2` |
| ☆ | `81 99` |
| ◆ | `81 9F` |
| 注 | `92 8D` |

レコード番号（1始まり）は `um_dat_record_no()` が計算する。

```
record_no = 2 × 開催日目 + レース番号 − 11
```

この式は開催日ごとに2レコード（11R・12R）が並ぶ前提になっている。G1 は 11R 施行が大半なのでそのまま使えるが、他のレース番号に転用するときは実ファイルで確認すること。

印の意味づけ（◎＝本命、注＝抑え など）は `public/馬券の印ルール.md` に書いてある。

## 成績コメント（KEK_COM）

Shift_JIS・CRLF のテキストファイル。1行1レコード。

```
{競馬場コード}{YY}{開催コード}{レース番号2桁}{馬番2桁},"コメント"
```

例:

```
0926341102,"[宝塚記念] 0.3秒差2着。"
```

`09`=阪神 / `26`=2026年 / `34`=3回4日目 / `11`=11R / `02`=馬番2。

コメント本文が `[レース名] 本文` の形式になっているのは `gen_result_comment` が付けた定型文の名残で、`gen_predict` / `gen_result` はこの `[...]` を分離してレース名として扱う。

### 読み込み

- `find_kek_com_file()` … 対象ファイルのパスを返す。存在しなければ `None`。
- `read_kek_comments()` … 指定レースの全馬コメントを `{馬番: コメント}` で返す。**ファイルが無い場合は空の辞書を返す**（例外にはならない）ので、コメントが出ないときはまずファイルの存在を疑う。

### 書き込み

- `write_kek_comment()` … 1行を**追記**する。
  - ファイルが無い場合は `FileNotFoundError`（新規作成はしない）。
  - コメントにダブルクォートが含まれると `ValueError`。改行は除去される。
  - 追記専用なので、同じレースで `gen_result_comment` を2回走らせると同じ行が二重に入る。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| 予想記事の `## 印` が空 | `TFJV_DATA_DIR` の指定、`UM{YY}{回}{場略称}.DAT` の存在、TARGET 側で印が保存されているか |
| 見解・回顧のコメントが出ない | `KEK_COM/20{YY}/KC*.DAT` の存在（無いと黙って空になる）、対象馬のコメントが入力済みか |
| `Unsupported venue code` | 地方・海外のレースコードを渡していないか（JRA10場のみ対応） |

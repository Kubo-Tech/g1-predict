# trend系の DataInterface 依存削除

## 概要

`_trend_loader.py` / `trend_section.py` に残存していた `DataInterface` 引数を削除し、
`di.get_result()` / `di.get_payoff()` を `RaceGetter.get_umagoto_race_joho()` /
`get_haraimodoshi()` に置換する。合わせて `race_info` の日本語カラム参照を raw 英語カラム名に統一する。

`prev_day_trend.py` の `build_prev_day_trend_section()` から `di` 引数を削除して関数内で
`DataInterface` を初期化する形に変更。`gen_predict.py` にコンフリクト解決で欠落していた
前日の傾向・trend セクションの呼び出しを復元する。

## 変更内容

### 既存ファイルの変更

- `g1_predict/modules/gen_predict/_trend_loader.py`: DataInterface 依存を削除
  - `di` 引数削除
  - `di.get_result()` → `rg.get_umagoto_race_joho(race_code=rc, convert_codes=False)`
  - `di.get_payoff()` → `rg.get_haraimodoshi(race_code=rc, convert_codes=False)`
  - `race_info["競馬場コード"]` → `race_info["keibajo_code"]`
  - `race_info["距離"]` → `race_info["kyori"]`
  - `race_info["特別競走番号"]` → `race_info["tokubetsu_kyoso_bango"]`
  - `race_info["芝ダ"]` → `TRACK_CODE_TO_SHIBA_DA.get(track_code, "")`
  - `result_df["血統登録番号"]` → `result_df["ketto_toroku_bango"]`
  - フォールバック目的の `try/except Exception` ブロック削除
- `g1_predict/modules/gen_predict/trend_section.py`: DataInterface 依存を削除
  - `di` 引数削除
  - `race_info["開催年"]` → `race_info["kaisai_nen"]`
  - `load_db()` 呼び出しから `di` 削除
- `g1_predict/modules/gen_predict/prev_day_trend.py`: DataInterface の初期化を外部注入から内部初期化に変更
  - `build_prev_day_trend_section()` から `di` 引数削除、関数内で `DataInterface("mykeibadb")` を初期化
  - `race_info["競馬場コード"]` → `race_info["keibajo_code"]`
  - `race_info["芝ダ"]` → `TRACK_CODE_TO_SHIBA_DA.get(track_code, "")`
  - `_TRACK_CODE_TO_SHIBA_DA` をモジュール公開変数 `TRACK_CODE_TO_SHIBA_DA` に変更（他モジュールからのインポート用）
- `scripts/gen_predict.py`: コンフリクト欠落分の復元とバグ修正
  - `generate_predict()` に `build_prev_day_trend_section()` / `_build_trend_sections()` 呼び出しを復元
  - `_render_from_template()` への `trend_section` / `trend_sections_map` 引数追加
  - `_build_trend_sections()` から `di` 引数削除
  - `_build_insight_section()` の `_GRADE_CODE_DISPLAY` 参照を `GRADE_CODE_DISPLAY` に修正
  - `_build_insight_section()` の未定義変数 `count` を修正（ループカウンタとして定義）
  - `_build_insight_section()` の未使用引数 `race_code` 削除

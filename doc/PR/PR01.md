# keiba-data-interface依存削除とDataInterface撤廃

## 概要

`requirements.txt` から `keiba-data-interface` 依存を削除し、`scripts/` 配下のスクリプトで使用していた `DataInterface` を `mykeibadb.RaceGetter` に全面置換する。

## 変更内容

### 既存ファイルの変更

- `requirements.txt`: `keiba-data-interface` 依存を削除
- `scripts/gen_predict.py`: `DataInterface` → `RaceGetter`。日本語変換済みカラム名をrawの英語カラム名に変更（`kyosomei_hondai` / `kaisai_nen` / `umaban` / `bamei` / `ketto_toroku_bango` / `race_code` / `grade_code`）
- `scripts/gen_result_comment.py`: `DataInterface` → `RaceGetter`。日本語変換済みカラム名をrawの英語カラム名に変更（`kyosomei_ryakusho_6` / `kakutei_chakujun` / `time_sa` / `chakusa_code1` / `umaban` / `ijo_kubun_code`）

## テスト内容

### 既存ファイルの変更

- `test/unit/scripts/gen_predict/test_generate_predict.py`: `_make_mock_di` を `_make_mock_race_getter` に置換。`get_race_shosai` / `get_umagoto_race_joho` のモックを英語rawカラム名で構築。`get_umagoto_race_joho` は `race_code` / `ketto_toroku_bango` kwarg で戻り値を切り替える `side_effect` を使用
- `test/unit/scripts/gen_result_comment/test_generate_result_comments.py`: `_make_mock_di` を `_make_mock_race_getter` に置換。各テストケースのカラム名を英語rawカラム名に変更
